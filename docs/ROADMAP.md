# Roadmap

当前开发策略：先把 NAS 本地整理、绿联兼容输出、手机端体验和长期维护做稳定，再扩展更高级能力。

## 已完成

### v0.1.3：绿联兼容输出

- 家庭影像 UI 无季，底层使用 `Season 01`。
- Episode 使用 scraper-friendly 文件名。
- NFO、集合海报/背景、单集图片生成。
- 已在绿联影视中心实机验证可正确归组。

### v0.1.4：集合维护

- 已整理集合发现与详情页。
- 集合 / Episode NFO 二次编辑。
- 向已有集合增量追加 Episode。
- 完整性检查和快速修复。
- NFO 覆盖写入与增量任务可撤销。

### v0.1.5：批量文件夹生成集合

- 媒体目录支持勾选多个可处理文件夹。
- 一个文件夹自动对应一个集合，默认使用文件夹名称。
- 自动过滤空目录、无视频目录、已整理或疑似已整理集合。
- 批量模式采用浅层扫描，不递归合并子文件夹。
- 批量执行前统一预览，并保留冲突检测、失败回滚和整体撤销。

### v0.1.6：移动端体验

- 360～430px Android 竖屏作为主要适配范围。
- 固定底部导航与底部安全区域适配。
- 文件浏览卡片化、整行触控选择、固定操作栏。
- 表单单列化和触控区域优化。
- 截图候选横向滑动。
- 长路径和批量预览适配窄屏。

### v0.1.7：轻量更新机制

- Docker Runtime 与应用代码分离。
- 稳定 Runtime Launcher 管理 Uvicorn 子进程并支持应用热切换重启。
- GitHub Release 发布轻量 app 更新包和 SHA256 清单。
- 设置页支持检查更新、一键安装和版本回滚。
- `RUNTIME_API` 阻止不兼容应用代码覆盖旧运行环境。
- 普通应用版本不再要求 NAS 重新下载 Python / FFmpeg Docker 层。
- CI 仅在 Runtime 文件变化时构建 amd64 + arm64 Docker Runtime。

## v0.1.x 下一步

优先方向：

- 国内镜像 / 自定义更新源，进一步降低 GitHub Release 在国内网络下的不稳定影响。
- PWA / 添加到 Android 主屏幕。
- 集合海报 / 背景图在维护页直接重新上传、从已有视频重新截图。
- 批量单集封面候选生成、快速确认与替换。
- Episode 调整顺序、插入中间集数时的安全重编号方案。
- 集合扫描缓存，避免超大 NAS 媒体目录每次全量遍历。
- 任务历史、错误提示与异常恢复继续完善。

## 后续版本

### 多媒体源

- 电脑本地文件处理。
- Windows / macOS / Linux 本地执行 Agent。
- 其他 NAS 或网络共享目录。

### 更多媒体平台

在内部数据模型稳定后再考虑输出适配层：

- Jellyfin
- Emby
- Kodi / 通用 NFO

### AI 能力

AI 暂不进入当前基础版本。未来可以作为可选能力：

- 根据文件名、目录和时间生成命名建议。
- 视频抽帧理解与自动分类。
- 自动生成标题、简介和标签。
- 语音转文字与内容摘要。

AI 能力应保持可关闭，并与基础文件整理能力解耦。
