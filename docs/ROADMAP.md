# Roadmap

当前开发策略：先把 NAS 本地整理、绿联兼容输出和长期集合维护做稳定，再扩展更高级能力。

## 已完成

### v0.1.3：绿联兼容输出

- 家庭影像 UI 无季，底层使用 `Season 01`。
- Episode 使用 scraper-friendly 文件名。
- NFO、集合海报/背景、单集图片生成。
- 已在绿联影视中心实机验证可正确归组。

### v0.1.4：集合维护

- 已整理集合发现与详情页。
- 集合 / Episode NFO 二次编辑。
- 向已有集合增量追加 Episode。
- 完整性检查：tvshow、poster、fanart、Episode NFO/JPG、断号、重复集数。
- 缺失 NFO / Episode JPG 快速修复。
- NFO 覆盖写入与增量任务可撤销。

## v0.1.x 下一步

优先方向：

- 集合海报 / 背景图在维护页直接重新上传、从已有视频重新截图。
- 批量单集封面候选生成、快速确认与替换。
- Episode 调整顺序、插入中间集数时的安全重编号方案。
- 集合扫描缓存，避免超大 NAS 媒体目录每次全量遍历。
- 任务历史、错误提示与异常恢复继续完善。

## 后续版本

### 多媒体源

- 电脑本地文件处理。
- Windows / macOS / Linux 本地执行 Agent。
- 其他 NAS 或网络共享目录。

### 更多媒体平台

在内部数据模型稳定后再考虑输出适配层：

- Jellyfin
- Emby
- Kodi / 通用 NFO

### AI 能力

AI 暂不进入当前基础版本。未来可以作为可选能力：

- 根据文件名、目录和时间生成命名建议。
- 视频抽帧理解与自动分类。
- 自动生成标题、简介和标签。
- 语音转文字与内容摘要。

AI 能力应保持可关闭，并与基础文件整理能力解耦。
