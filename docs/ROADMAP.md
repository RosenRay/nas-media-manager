# Roadmap

当前开发策略：先把 NAS 本地整理与绿联兼容输出做稳定，再扩展更高级能力。

## v0.1.x：基础可用与集合维护

优先方向：

- 已整理集合管理：重新进入集合编辑标题、简介、海报、背景图和单集信息。
- 增量新增视频：向已有集合追加 Episode，不重做整个集合。
- 完整性检查：缺失 NFO、缺失单集图片、编号断档、集合级海报缺失等。
- 更高效的批量封面确认与重新截图流程。
- 任务历史和异常提示继续完善。

## 后续版本

### 多媒体源

- 电脑本地文件处理。
- Windows / macOS / Linux 本地执行 Agent。
- 其他 NAS 或网络共享目录。

### 更多媒体平台

在内部数据模型稳定后再考虑输出适配层：

- Jellyfin
- Emby
- Kodi / 通用 NFO

### AI 能力

AI 暂不进入当前基础版本。未来可以作为可选能力：

- 根据文件名、目录和时间生成命名建议。
- 视频抽帧理解与自动分类。
- 自动生成标题、简介和标签。
- 语音转文字与内容摘要。

AI 能力应保持可关闭，并与基础文件整理能力解耦。
